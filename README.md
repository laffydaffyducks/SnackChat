# SnackChat

SnackChat is an AI powered Calorie Tracker application

* **Fast Quantitative Data:** With a quick drag and drop image feature. A quick calorie estimate is provided with an adjustable weight setting.
* **Track Calorie Goals:** Set calorie or nutrition goals and SnackChat will provide Suggestion Feedback to guide you towards those goals.
* **Accountability:** Notifications to help you stay on track throughout your Health/Fitness journey



## Installation


1. First clone the repository on to your local system
2. Create an [OPENAI](https://openai.com/api/) account and [Food Calorie Ninja](https://calorieninjas.com/api) account
3. Create a .env file in the server folder with these two API keys:
    * OPENAI_API_KEY=\<yourOPENAPIKey>
    * CALORIE_NINJAS_API=\<yourCalorieNinjaAPIKey>
## Running Application

1. Split Terminal and choose directory:
    * cd server
        * npm run server
    * cd cliet
        * npm run dev

2. Open [http://localhost:5173/](http://localhost:5173/)

3. Drag image into the image drop

4. Once image is processed either make alterations to the weight or press submit
